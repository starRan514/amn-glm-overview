一 · 任务集实施不等同于动作执行

对 AMN trial 中 start、maintenance、trial 与 response 的区分，最自然的理论入口是 task-set implementation，而不是将所有 task-positive 模式一概叫作“控制”。

与 Dosenbach 等人的关系

从任务规则到可执行的控制状态

Dosenbach 等人对 core system / task-set 的描述支持这样一种工作解释：任务开始、维持和反应不是彼此无关的时间点，而是将规则、目标与行动要求转译为可执行状态的不同阶段。AMN 中的阶段性 contrast 因而可被用来定位“相对动作执行仍保留的任务集相关成分”。

这不意味着 AMN 的每一处活动都具有同一功能，也不意味着网络边界就是心理过程边界。更严谨的表达是：AMN trial 模型为“任务集实施与反应执行至少部分可分”提供了设计层面的检验。

二 · preResponse 是动作准备的候选窗口，而不是标签答案

SCAN response 将 left/right preResponse 与 response 同时纳入 GLM，这一设计比两张独立图的空间比较更接近“分离”问题。

可支持的解释

动作前状态可以包含多个成分

反应前活动可共同承载刺激证据累积、冲突解决、反应选择、效应器准备和阈值调节。因而 preResponse − response 的空间差异并不要求它们是两个绝对独立网络；它更可能是同一控制链条在不同时间窗和不同信息需求下的状态变化。

在当前模型中，更准确的说法是：“在共同控制 response EV 的条件下，preResponse 仍有独立的估计结构。”这为准备性过程提供候选神经表征，但尚不能仅凭空间图决定其具体成分。

关键的后续检验

用行为把“准备”变成可证伪假设

  • preResponse 强度能否预测 trial-level 反应时、反应时变异或错误？
  • 这种预测在 incongruent 条件是否更强？
  • preResponse 的 FIR 时程是否在行为困难增加时提前、延长或增幅？
  • 其与下一试次控制调整或 post-error slowing 是否相关？

三 · 冲突效应应按阶段定位

SW-FIR-DG 和 FIR-DG-FIR-DG 都包含 incongruent > congruent，但分别位于 maintenance、preResponse 和 response 阶段。理论问题由此从“有没有冲突激活”变成“冲突调制首先、主要或仅在哪个阶段出现”。

可检验的阶段假设

维持、准备与执行可有不同的冲突角色

若冲突差异主要出现在 maintenance，可优先考虑规则维持、预期或控制状态的持续调节；若主要出现在 preResponse，可考虑反应选择、竞争解决或动作阈值配置；若主要出现在 response，则更接近执行阶段的条件调制。这些都只是阶段化假设，需结合条件间时程、行为代价和独立复制来评估。

使用 FIR 的优势在于不强迫 preResponse 遵循单一 canonical HRF 形状。因此，若 FIR 与 double-gamma 版本都指向相近的阶段性结论，报告的可信度会提高；若二者不一致，则“不确定性”本身是重要结果。

四 · maintenance 与 response 的重叠：优先审查建模，而非急于命名脑功能

时间建模的含义

共享方差是合理的候选解释

maintenance 是持续期 EV，而 response 是短暂 canonical-HRF EV；二者在真实任务中时间相邻并可能部分重叠。若 maintenance − response 仍有结构性结果，表明在该设计矩阵下仍可区分的方差存在；若两者的未校正空间图重叠，也不等价于“二者是同一过程”。

最有价值的下一步是导出/检查设计矩阵相关性、FIR 时间曲线和 trial-level 行为耦合，而不是依据一张组水平表面图断定 maintenance 已经包含了某种确定的 response 信号。

五 · 解释边界与汇报措辞

可以说：“在特定的 withWM 一级 GLM 中，阶段间 contrast 显示可区分的空间估计模式。”
不应直接说：“某网络在因果上驱动了另一个网络”，或“任何与行为有关的区域都特异地实施某一心理过程”。
去白质信号放在最后

敏感性分析不改写主发现的证据等级

去除白质信号后结果若与 withWM 结果接近，可以作为处理选择下的稳健性线索；若改变明显，则应报告依赖性并探索来源。它既不能证明白质传播机制，也不能自动证明 withWM 或 deWM 中某一版本更“真实”。主页面首先呈现 withWM，是因为它与实际设计和当前主要图的证据链保持一致。

六 · 推荐的国际会议叙事

第一步：展示模型审计：不同 EV、FIR / 持续期 / double-gamma 的建模含义，以及 contrast 对应的问题。

第二步：报告 withWM 主结果：试次期相对 response 的差异、SCAN 中 preResponse 与 response 的分离，以及条件调制在阶段上的定位。

第三步：把这些结果连接到“任务集实施 → 准备/选择 → 执行”的工作模型，同时明确是可检验框架而非因果结论。

第四步：最后用 deWM 配对结果讨论稳健性与局限。
