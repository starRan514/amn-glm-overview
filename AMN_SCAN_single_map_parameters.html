AMN-SCAN 单图表面绘制：参数参考

学生版 脚本：brain_surface_visualize_AMN-SCAN.py。输入一张三维 MNI152 NIfTI 图，输出一张四面板 AMN-SCAN 表面图。

1. 最短使用示例

python brain_surface_visualize_AMN-SCAN.py \
  /path/to/zstat1.nii.gz \
  /path/to/output \
  cope10_right_response \
  --overwrite

默认使用 fsaverage6、41k 顶点、0.4 × pial + 0.6 × inflated、AFNI activation 色带和全局 AMN 内缩。

2. 输入、输出与色带

参数默认值含义
input_file必填一张三维 MNI152 .nii/.nii.gz 图，例如 FSL 的 zstat1.nii.gz。
output_dir必填结果目录。已有同名四面板 PNG 时默认跳过。
output_basename必填输出文件前缀，不含路径分隔符。
--overwrite关闭允许覆盖同名 PNG、投影和报告。
--mode activation|fcactivation选择 AFNI activation 色带或 FC 色带。FC 模式色带标题为 Z(r)。
--lut-file随模式选择自定义 LUT 图像。activation LUT 必须为 256 行。
--display-max自动activation：固定对称范围 [-M, 0, +M]；适合多图统一色带。
--display-min、--display-mid自动FC 模式推荐显式设置三个范围参数，且必须满足 min < mid < max。
# 多张 activation 图采用同一上限 M=5
python brain_surface_visualize_AMN-SCAN.py map.nii.gz out map --display-max 5 --overwrite

# FC 示例：显式给出 Z(r) 范围
python brain_surface_visualize_AMN-SCAN.py fc.nii.gz out fc --mode fc \
  --display-min 0.20 --display-mid 0.25 --display-max 0.30 --overwrite

3. 表面空间与参考轮廓

参数默认值含义
--surface-spacefsaverage6fsaverage5 使用 10k/10242 顶点；fsaverage6 使用 41k/40962 顶点。
--surface-dir按空间选择目标 FreeSurfer 表面目录，必须含 surf 和 label。
--surface-mix-pial、--surface-mix-inflated0.4、0.6两者必须相加为 1。
--amn-left-label、--amn-right-labelYeoVAN-PowerCON unionAMN 标签路径。
--amn-reference-spacefsaverage5fsaverage5：按 pial 最近顶点映射至目标空间；target：标签已在目标空间。
--scan-left-label、--scan-right-labelfsaverage6 自动查找SCAN 左右标签。使用 fsaverage5 时必须显式提供匹配的 fsaverage5 标签。
--scan-label-value1.5输入 SCAN GIFTI 中代表 SCAN 的数值。
AMN 与 SCAN 参考必须与目标表面顶点数匹配。只有 AMN 的 fsaverage5 来源标签允许映射到 fsaverage6；不要把 fsaverage6 的 SCAN 标签直接用于 fsaverage5。

4. 轮廓线与 AMN 内缩

参数默认值含义
--contour-width26AMN 黑线与 SCAN 白线的宽度。
--boundary-inset0.80边界在线段内外顶点之间的位置；基础位置为 0.90 p_in + 0.10 p_out。
--boundary-offset0.55轮廓向表面外侧抬起的距离，避免被皮层遮住。
--amn-collapse-scopeallall：所有 AMN 边界向内移动；near-scan：仅移动距离 SCAN 小于阈值的端点。
--amn-extra-inset0.05AMN 向内移动量：after = before + 0.05 × (p_in - p_out)。
--amn-scan-contact-mm4仅 near-scan 模式使用的三维距离阈值。
# 不内缩：将移动量设为 0
... --amn-extra-inset 0

# 仅靠近 SCAN 的 AMN 轮廓内缩，且增加内缩距离
... --amn-collapse-scope near-scan --amn-scan-contact-mm 6 --amn-extra-inset 0.08

5. AMN 小碎点筛除

默认只删除很可能由 fsaverage5→目标表面映射造成的碎片：目标连通块不超过 3 顶点、面积不超过 5 mm²，且回溯到同一个更大的 fsaverage5 原始连通块。

参数默认值含义
--amn-fragment-max-vertices3允许自动删除的最大目标顶点数。
--amn-fragment-max-area-mm25允许自动删除的最大估计面积。
--keep-amn-mapping-fragments关闭不删除，仅输出评估报告。

先查看 *_amn_fragment_removal.tsv：removed 是自动删除；kept 则说明它是独立来源、过大，或参数要求保留。

6. 输出文件

  • *_AMN-SCAN_4panel.png：带下方色带的左/右半球外侧和内侧四面板。
  • *_lh.func.gii、*_rh.func.gii：投影后的表面数值。
  • *_display_limits.tsv：实际绘图色带范围。
  • *_amn_fragment_removal.tsv、*_amn_component_report.tsv：AMN 碎片筛除与连通块记录。
  • *_amn_contour_adjustment.tsv：AMN 轮廓内缩前后的坐标。
运行前可先执行 python brain_surface_visualize_AMN-SCAN.py --help 查看全部参数。脚本需要 MNE、PyVista、Neuromaps、Nibabel、SciPy、Pillow 与 Matplotlib。
